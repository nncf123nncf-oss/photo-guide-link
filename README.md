# 撮ってほしい写真の見本リンク（photo-guide-link）

お見積もりの前にお客さんに撮ってほしい写真を、見本の図と撮り方のコツつきで順番に並べてリンクにする1ページの道具です。お客さんはリンクを見ながら撮り、撮れたものに印をつけ、「写真を○枚お送りします 1 本体の全体…」の添え文をコピーして、写真といっしょにLINEなどでお店に送ります。

- 内容はURLの `#` 以降に入ります。サーバー・アカウントは使いません
- **このページは写真を受け取りません。カメラも使いません。** 入力した内容はブラウザの中で処理します（閲覧数の計測に Cloudflare Web Analytics を使っています）
- 見本は同梱の図（SVG・8種）で、実際の写真ではありません
- リンク・メールアドレス・電話番号・LINE IDらしい文字と、身分証やお金に関わる書類（免許証・通帳など）の言葉は入れられないようにしています（すべての言い方は防げません）。店名には銀行・役所などの名前を入れられません
- 作る側の下書きはお使いの端末のブラウザ（localStorage）に保存します。開く側の「撮れた」の印はタブを閉じると消えます（sessionStorage）
